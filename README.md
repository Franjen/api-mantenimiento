
# API Mantenimiento

API REST para la gestión de mantenimiento de equipos, desarrollada con NestJS y TypeScript.

El proyecto se integrará posteriormente con Supabase, Prisma, Flutter y Render.

## Tecnologías

- Node.js
- NestJS
- TypeScript
- ESM
- Vitest
- Bruno
- Git y GitHub

## Instalación

npm install

## Ejecutar el proyecto

npm run start:dev

## Endpoint disponible

GET /health

URL: http://localhost:3000/health

Permite verificar el estado de funcionamiento de la API.

## Pruebas

- npm run build
- npm test
- npm run test:e2e

## Colección Bruno

La colección se encuentra en la carpeta bruno.

- Colección: api-mantenimiento
- Entorno: local
- Variable: baseUrl
- Valor: http://localhost:3000
- Petición: GET /health
- Validación: HTTP 200
